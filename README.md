A comprehensive GUI tool for visual and statistical analysis of spatial navigation data generated by the **Lyra Framework** (Non-Visual Spatial Navigation Environment).

This software is designed to support research in **Spatial Cognition**, **Blind Navigation**, and **Wayfinding**, providing metrics aligned with established scientific literature (Klatzky et al., Loomis et al., Golledge).

The executables is in the **Releases** page on this repository

---

## 📋 Features

**Lyra Analyser** processes telemetry CSV files and offers:

### 1. Data Visualization
- **Path Mapping (2D):** Visualizes the traversed path (X/Z) with a temporal gradient.
- **Event Visualization:** Visual markers for goal collection, collisions, and hazard zones.
- **Velocity Profile:** Instantaneous velocity plots with signal smoothing (Savgol filter).

### 2. Scientific Metrics
The system calculates advanced metrics for navigation behavior analysis:
- **Path Tortuosity Index:** Ratio between the distance traveled and the straight-line Euclidean distance.
- **Movement Entropy:** Measure of movement predictability vs. randomness (0 to 1).
- **Path Efficiency:** Trajectory optimization analysis.
- **Safety Analysis:** Time spent in danger zones (<1m) and warning zones (1-2m).

### 3. Reports & Export
- **Scientific Report Generation:** Exports a detailed `.txt` with a statistical summary ready for publication.
- **Figure Export:** Saves high-resolution plots for use in academic papers (PNG).
- **Session Comparison:** Comparative table for multiple tests or participants.

## 🛠️ Installation

### Prerequisites
If you use the source code, ensure you have Python 3.8+ installed. The core dependencies are standard scientific libraries.

1. Clone the repository:
```bash
git clone [https://github.com/joaotemochko/Lyra_Analyser.git](https://github.com/joaotemochko/Lyra_Analyser.git)
cd lyra_analyser
```

2. Install Python Libraries
All necessary dependencies can be installed directly via pip. You do not need a separate requirements file.

```bash
pip install pandas numpy matplotlib scipy
```

Note: The interface relies on tkinter, which is typically included with standard Python installations. If you are on Linux and encounter an error, you may need to install it manually (e.g., sudo apt-get install python3-tk).

## 🚀 Usage
The main application file is located in the src folder.

### Running the Application (Source code)
Execute the script from the root directory:

```bash
python src/lyra_analyser.py
```

## Workflow
Load Data: Click "Load CSV" to import a Lyra data file.

Analyze: Use the side panel to navigate between views (Path, Metrics, Goals, Safety).

Generate Report: Click "Run Full Analysis" to generate complete statistics inside the "Report" tab.

Export: Use the File > Export Report menu to save the analysis to a text file.

Data Format Requirements
The tool accepts CSV files (using , or ; delimiters) containing the following columns:

timestamp: Absolute time.

elapsed_time: Time elapsed since start (seconds).

event: Event type (TRACK, COLLECT, ENTER, etc.).

x, z: Spatial coordinates (meters).

velocity: (Optional) Instantaneous velocity.

dist_boundary: (Optional) Distance to nearest wall.
